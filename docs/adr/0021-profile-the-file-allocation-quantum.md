# Make the file allocation quantum part of the capacity profile

The B+ tree format expresses extent positions and spans in a compile-time `allocationQuantumBytes` value that is persisted numerically in the authenticated capacity profile and must match exactly on open. `DefaultLimits` uses 4 KiB; custom profiles may select any power of two from 512 bytes through 64 KiB inclusive. Every permitted value must be implemented correctly and portably, but v1 performance qualification and optimization apply only to the 4 KiB default; this allows specialized applications to trade alignment, metadata scale, and compression rounding without pretending that the choice is a runtime property or universally interchangeable format.
