# Expose structural metadata outside Protected extent payloads

Protected-extent preambles visibly identify unit role and, for suite 1, key domain, physical bounds, encoded and decoded sizes, compression representation, generation and sequence, Blob ownership, and nonce. Suite 1 encrypts application keys, Values, Blob bytes, and allocation content; suite 0 stores them as plaintext. Neither mode promises structural hiding or deniability. Accepting this visibility makes extents independently classifiable and bounded for offline inventory and verification rather than requiring a trusted parent graph merely to understand the file's physical contents.
