# Require byte-level corruption classification

Qualification mutates every format layer and authenticated unit role across fixed representative fixtures, including truncation, relocation, replay, substitution, compressed-frame damage, and cross-database or cross-Blob swaps. Passing requires exact public classification—visible compatibility rejection, bootstrap `AuthenticationFailed`, permitted incomplete-publication fallback, or committed `Corrupt`—plus correct handle transitions, sentinel proof that no unauthenticated plaintext escapes, and no crash, hang, overread, unbounded allocation, or sensitive diagnostics; whole-file rollback remains intentionally undetected.
