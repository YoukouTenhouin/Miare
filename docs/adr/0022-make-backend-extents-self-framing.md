# Make every backend extent self-framing

Every B+ tree page, overflow value, Blob manifest, Blob chunk, and allocation structure begins with a canonical bounded preamble and contains its own protected payload and protection trailer. Suite 1 uses the released nonce, ciphertext, and authentication tag; suite 0 uses zero nonce fields, plaintext, and an unkeyed checksum. Its protected parent separately supplies the expected physical extent, role, generation, and encoded bounds, all of which must agree before decoded content is released. The duplicated metadata and allocation rounding are accepted so independent implementations can use one fail-closed unit parser and offline tooling can bound, inventory, and verify extents without first trusting a complete parent graph.
