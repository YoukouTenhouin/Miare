# Store each overflow Value in one Protected extent

A Value larger than the capacity profile's inline cutoff is stored in one self-framing Protected extent containing its complete logical bytes, optionally compressed as one unit, and its leaf entry carries the logical length and one direct extent reference. Reads protection-check and decode the complete extent before returning the already-promised owned in-memory Value. This may require a contiguous allocation up to `maxValueBytes`, but avoids a manifest and multi-unit read path for ordinary Values; applications needing incremental or substantially larger content use Blobs instead.
