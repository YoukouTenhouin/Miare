# Use one bounded Zstandard frame per eligible authenticated unit

Zstandard profile 1 uses one RFC 8878 frame at level 3 with a 16 MiB maximum window, explicit content size, no dictionary, no checksum, and no worker threads. The representation is retained only when the payload shrinks and the complete framed extent consumes at least one fewer Allocation quantum; otherwise it is canonical uncompressed data. This keeps decoding bounded and provider versions replaceable, and omits the frame checksum because the surrounding XChaCha20-Poly1305 tag already authenticates the frame, while accepting that compatible provider output can change the physical compressed/uncompressed choice.
