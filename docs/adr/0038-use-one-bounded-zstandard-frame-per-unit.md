# Use one bounded Zstandard frame per eligible Protected unit

Zstandard profile 1 uses one RFC 8878 frame at level 3 with a 16 MiB maximum window, explicit content size, no dictionary, no frame checksum, and no worker threads. The representation is retained only when the payload shrinks and the complete framed extent consumes at least one fewer Allocation quantum; otherwise it is canonical uncompressed data. This keeps decoding bounded and provider versions replaceable. The surrounding suite-1 authentication tag or suite-0 corruption checksum covers the stored frame; only the former resists adversarial modification. Compatible provider output may change the physical compressed/uncompressed choice.
